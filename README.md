# Interview-AI

AI-Powered Mock Interview Platform.

## Project Structure

- `Backend/`: Node.js / Express backend API server.
- `Frontend/`: React / Vite frontend application.

## Getting Started

### Backend Setup
1. `cd Backend`
2. `npm install`
3. Configure `.env` file.
4. `npm start` or `node server.js`

### Frontend Setup
1. `cd Frontend`
2. `npm install`
3. `npm run dev`
